# Подпись обновлений «Заказы»

Все распространяемые тестовые APK должны использовать исходный ключ из
`Orders_Test_Signing_Recovery.zip`. Его сертификат SHA-256:
`82a94fb920b5eb7ef1afe9ab250b0f59d3fecf52ec789fad9734b83eb7a73200`.

В Settings → Secrets and variables → Actions добавить секрет
`ORDERS_DEBUG_KEYSTORE_BASE64`: Base64 файла `debug.keystore` из этого архива.
Пароль хранилища/ключа — стандартный тестовый `android`, alias — `androiddebugkey`.
Сам ключ, его Base64 и архив восстановления нельзя коммитить.

Actions восстанавливает ключ во временный файл с правами 0600, проверяет сертификат,
собирает APK и удаляет файл. При отсутствии или несовпадении ключа сборка прекращается.
APK из pull request не публикуется: сторонним PR ключ не предоставляется.

Версия интерфейса — 0.4. В Actions код версии равен номеру запуска (не менее 4),
в локальной сборке — 4. Повторный запуск одного workflow сохраняет код версии.
Для локальной подписи задать `ORDERS_KEYSTORE_PATH` с абсолютным путём к исходному ключу.

Сборка №44 ранее была подписана случайным ключом GitHub runner.
Она не может обновлять 0.1/0.2 с исходной подписью. Переизданный APK №44 подписан
исходным ключом; его код/название версии остаются 2/0.2-debug.
