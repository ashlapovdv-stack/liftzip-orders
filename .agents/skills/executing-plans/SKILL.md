# Выполнение плана

1. Прочитать исходное ТЗ, план, правила проекта и фактическое состояние ветки. Сопоставить уже сделанное с коммитами и результатами; продолжить с первого незавершённого этапа.
2. Выполнять зависимые этапы по порядку. В разрешённом объёме самостоятельно решать обычные технические вопросы; не останавливаться после каждого этапа для повторного разрешения.
3. При несоответствии плана исходникам проверить причину, внести минимальную обоснованную поправку и записать решение. Не подменять цель задачи.
4. После этапа проверить его результат. При сбое использовать systematic-debugging, не маскировать ошибку отключением тестов.
5. Для длительного плана отмечать завершённые результаты и фактические команды рядом с планом; не сохранять секреты, реальные письма или базы.
6. Перед завершением выполнить requesting-code-review и verification-before-completion. Не поручать работу другим моделям или агентам без разрешения.
Если блокируется только один этап, продолжить независимую разрешённую работу и сообщить конкретный блокер. Новые последствия вне разрешённого объёма согласовать до их выполнения.
