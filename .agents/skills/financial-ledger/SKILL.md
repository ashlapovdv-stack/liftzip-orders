# Расчёты Заказов

1. Читать актуальное ТЗ, AGENTS.md, domain-модуль и принятые примеры. Не выводить формулы из подписей UI или старой переписки без сверки.
2. Использовать BigDecimal/decimal-строки или целые минимальные единицы. Явно задавать валюту, точность, место и режим округления; не использовать Float/Double для денег.
3. Различать неизвестное значение и ноль, доход, расход и передачу денег, прогноз и фактический счёт. Не учитывать одну доставку или старый долг повторно.
4. Курс заказа хранить для истории и брать из сохранённого заказа; не пересчитывать исторические суммы по текущему внешнему курсу. Проверять направление конвертации и единицы тарифа.
5. Исправлять утверждённые финансовые операции корректировкой/сторно согласно модели проекта. Не переписывать финансовую историю ради нового интерфейса.
6. Составлять эталонные примеры вручную независимо от кода: валюта, вес, тариф, доставка, null, ноль, округление, перенос долга, повторная операция и сохранение/открытие.
7. Отображение целых сумм без ,00 не должно менять хранимую точность. Проверять экспорт и резервное восстановление при изменении данных.
