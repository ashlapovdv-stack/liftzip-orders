# Lift-ZIP · Заказы

Локальное Android-приложение учёта оплаченных заказов, расчётных групп и истории цен.

Это стартовый пакет требований, не готовое приложение.

- [Техническое задание](docs/TZ_Orders_Prototype_v1.md)
- [Правила разработки и работы с Kimi](AGENTS.md)

План: Kotlin, Jetpack Compose, MVVM, Room/SQLite. Первый этап 0.1 описан в ТЗ. Собственный сервер не нужен. Почта и MAX подключаются после проверки основного рабочего цикла.

Репозиторий: https://github.com/ashlapovdv-stack/liftzip-orders. Видимость Private проверена 11.11.2026.
